# Happy Birthday, My Princess! 💖

A digital birthday gift card website from a mother to her daughter, filled with love, memories, interactive animations, and maternal blessings.

## ✨ Features
- **3D Opening Gift Box**: Animated satin ribbon unboxing with heart bursts and background music.
- **Birthday Celebration**: 3-tier birthday cake with glowing candles, candle-blowing animation, and confetti cannons.
- **Handwritten Love Letter**: Mother's letter revealed line by line on parchment stationery with a wax seal.
- **14 Treasured Memories**: Polaroid scrapbook wall and cinematic slideshow album with filter categories.
- **Interactive Gifts**: 3 unboxing gifts (*A Hug 🤗*, *A Wish ✨*, *My Love ❤️*).
- **Final Scene**: Pulsing glowing pink heart with a framed portrait and a replay button.
- **Procedural Lullaby**: Gentle ambient piano music via Web Audio API.

## 🚀 Deployment & Hosting (GitHub Pages)
This project includes an automated GitHub Actions workflow in `.github/workflows/deploy.yml`.

### Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/chrisvjoseph07-rgb/happy-Birthday`
2. Click **Settings** > **Pages** (on the left menu).
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. That's it! Your site will automatically build and publish to:
   **`https://chrisvjoseph07-rgb.github.io/happy-Birthday/`**

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) to view it locally.
